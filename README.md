# Rowing & Sports Management System

A full-stack sports and rowing club management platform featuring athlete tracking, training schedules, equipment maintenance, and performance analytics.

## Tech Stack
* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
* **Backend:** FastAPI, Python 3.11, SQLAlchemy 2.0, Pydantic v2
* **Database:** Microsoft SQL Server (Localhost/SSMS) or Aiven.io (Managed Cloud MySQL)
* **Deployment:** Vercel (Backend Serverless) + Shared Node Server / Web Host (Frontend)
